# paper/

Reproducible experiments and figures for the thesis and paper. Every number that appears in the text is emitted as JSON by a script here; every figure is regenerated by `make figures`.

| Folder | Chapter | Fills in |
|---|---|---|
| `analysis/` | 3, analysis of CPDPM v1 | Week 2–3. Affine-map demonstration, keyspace count, key-in-package check, context-key non-determinism, fair re-benchmark of the client harness. |
| `construction/` | 4, the v2 design | Week 3–6. Known-answer vectors, encoding-injectivity evidence, size overhead table. |
| `evaluation/` | 5, evaluation | Week 6–8. Record-swap attack against v1, plain AES-GCM and v2; pyperf benchmarks against AES-GCM, Fernet and Tink on `data/healthcare-dataset-stroke-data.csv` and synthetic FHIR bundles. |
| `figures/` | all | Generated output only. Never edit by hand. |

Conventions: scripts are runnable from the repo root as `python -m paper.<folder>.<name>`; results are written to `paper/<folder>/results/*.json` (gitignored except the final pinned run); figures are PDF for the paper and PNG for the post.

Dataset: the stroke prediction dataset (5,110 rows) is public and contains no direct identifiers. It is used as realistic record content, not for any clinical inference. Cite the Kaggle source in the thesis.
