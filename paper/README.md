# paper/

Reproducible experiments and figures for the thesis and paper. Every number that appears in the text is emitted as JSON by a script here; every figure is regenerated by `make figures`. The chapter-by-chapter map from claims to result files is in [outline.md](outline.md).

| Folder | Chapter | Contents |
|---|---|---|
| `analysis/` | 3, analysis of CPDPM v1 | `affine_map.py`, `context_key.py`, `client_build.py`, `fair_benchmark.py`, `make_figures.py` |
| `construction/` | 4, the v2 design | `gen_kat.py` writes the known-answer vectors in `tests/vectors/` |
| `evaluation/` | 5, evaluation | `records.py` (FHIR-shaped payloads from the stroke dataset), `record_swap.py` (attack matrix), `benchmark.py` (pyperf), `summarize.py`, `make_figures.py` |
| `diagrams/` | 4, 5 | Hand-authored SVG sources for the explanatory figures (key hierarchy, wire formats, manifest, baseline comparison, record-swap sequence). `render.py` makes PDFs with svglib; the committed PNG/PDF pairs were rendered in Chromium for exact fonts. |
| `figures/` | all | Generated output only. Charts from scripts, diagrams from `diagrams/*.svg`. Never edit by hand. |

## Running

```bash
make analysis          # chapter 3 results  -> paper/analysis/results/*.json
make evaluation        # chapter 5 results  -> paper/evaluation/results/*.json  (minutes)
make evaluation-fast   # same with pyperf --fast, for a quick look
make figures           # every figure and table -> paper/figures/
make all               # test + analysis + evaluation + figures
```

Or from a clean container: `docker build -t cpdpm-paper . && docker run --rm cpdpm-paper`.

Scripts are modules, runnable from the repo root as `python -m paper.<folder>.<name>`. Results directories are gitignored except for the pinned run that the committed figures were made from (`git add -f`).

## Dataset

The stroke prediction dataset (5,110 rows, `data/healthcare-dataset-stroke-data.csv`) is public and contains no direct identifiers. It supplies realistic record shapes and sizes only; no clinical inference is made. Cite the Kaggle source in the thesis.
